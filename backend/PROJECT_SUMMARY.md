## ⚠️ 已知问题和解决方案

### 问题1: SQLAlchemy与Python 3.13兼容性
**状态**: 已知问题，有解决方案
**影响**: 在Python 3.13上运行时可能出现类型注解警告
**解决方案**: 
- 使用Python 3.11或3.12（推荐）
- 或等待SQLAlchemy更新版本
- 临时方案：忽略警告或降级SQLAlchemy

### 问题2: 依赖安装超时
**状态**: 已提供解决方案
**影响**: 网络问题可能导致安装失败
**解决方案**:
- 使用`install_deps.py`脚本分步安装
- 使用国内镜像源
- 手动安装核心依赖

### 问题3: Alembic命令行工具
**状态**: 已提供替代方案
**影响**: 系统路径中可能找不到alembic命令
**解决方案**:
- 使用`python -m alembic`代替`alembic`
- 或安装到用户目录：`pip install --user alembic`
